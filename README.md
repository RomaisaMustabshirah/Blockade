# Blockade

A falling-block puzzle game built in Unity 6. Blocks drop from the top of the board, and when four or more blocks of the same color line up, they disappear with a pop sound and add to your score.

## Gameplay

- Blocks fall one after another into the play area.
- Move and place them to line up 4 blocks of the same color.
- Matched blocks pop and clear, making room for more.
- Your score and high score are shown at the top of the screen.
- When the board fills up, the game ends and you can hit **Try Again**.

## Features

- Color-matching mechanic (match 4 to clear)
- Pop sound effects and background music
- Score and high score tracking
- Game over screen with restart

## Built with

- Unity 6 (6000.5)
- C#
- Visual Studio Code

## Run it locally

1. Clone the repo:
   ```bash
   git clone https://github.com/RomaisaMustabshirah/Blockade.git
   ```
2. Open the folder in Unity Hub (Add → Add project from disk).
3. Open the `Main` scene and press **Play**.
